# NEXORA TECH - Responsive Landing Page

## Description
A modern, premium, dark-themed responsive landing page for a fictional technology brand, **NEXORA TECH** ("Technology That Moves You Forward"). Built with only HTML5 and CSS3.

## Objectives
- Practice semantic HTML5 structure
- Use CSS Flexbox and Grid for layouts
- Build a fully responsive design (320px to 1440px+)
- Apply accessibility and clean-code best practices

## Technologies Used
- HTML5
- CSS3 (Flexbox, Grid, Custom Properties, Media Queries)
- Google Fonts (Inter)
- No JavaScript, no frameworks

## Main Features
- Sticky navigation bar with a "Get Started" button
- Hero section with a CSS-only visual panel
- Services section (3 cards, CSS Grid)
- About section with three highlights
- Call-to-action section and footer
- Hover effects, keyboard focus styles, smooth scrolling
- Reduced-motion support

## Run Locally
1. Download or clone the project.
2. Open the folder in VS Code.
3. Install the **Live Server** extension.
4. Right-click `index.html` and choose **Open with Live Server**.
(Or simply double-click `index.html` to open it in a browser.)

## Responsive Design
| Device  | Width        | Layout                                  |
|---------|--------------|-----------------------------------------|
| Mobile  | 320 - 430px  | Single column, nav links on second row  |
| Tablet  | 768px        | Wider spacing, 3-column footer          |
| Laptop  | 1024px       | Two-column hero and about sections      |
| Desktop | 1440px+      | Wider container                         |
